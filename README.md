# DIO-Bradesco-IA

Repositório desenvolvido durante o **Bootcamp Bradesco + Digital Innovation One (DIO)** com o objetivo de documentar os desafios, projetos e cadernos temáticos elaborados ao longo da formação.

Este espaço reúne estudos produzidos com apoio de **Inteligência Artificial Generativa**, **NotebookLM**, **Engenharia de Prompts** e **Agentes de IA**, demonstrando a aplicação prática de Large Language Models (LLMs) na organização, análise e consolidação do conhecimento.

O repositório tem como finalidade registrar a evolução técnica durante o bootcamp, servir como material de consulta para estudos futuros e compor um portfólio de projetos desenvolvidos ao longo da jornada.

---

# Objetivos

- Aplicar conceitos de Inteligência Artificial Generativa e Agentes Inteligentes na prática;
- Desenvolver habilidades em Engenharia de Prompts;
- Utilizar o NotebookLM para pesquisa e organização do conhecimento;
- Produzir cadernos temáticos estruturados sobre diferentes áreas de estudo;
- Desenvolver e documentar um Agente Inteligente funcional com LLM e RAG local;
- Consolidar aprendizados adquiridos durante o Bootcamp Bradesco + DIO;
- Construir um portfólio técnico organizado no GitHub.

3. Detecção de Anomalias em Transações Financeiras com Isolation Forest
Projeto desenvolvido em Python utilizando Jupyter Notebook com o objetivo de aplicar técnicas de Machine Learning para identificar transações financeiras potencialmente fraudulentas.

A solução utiliza o algoritmo Isolation Forest, um método de aprendizado de máquina não supervisionado especializado na detecção de anomalias em conjuntos de dados com elevado desbalanceamento. Para o estudo foi utilizada a base de dados Credit Card Fraud Detection.

Principais tópicos estudados:

Machine Learning & Algoritmo Isolation Forest

Análise Exploratória de Dados (EDA) e Pré-processamento

Detecção de Fraudes e Avaliação de Modelos

Python, Pandas, Scikit-learn e Matplotlib

📂 Acessar projeto: /Deteccao-Anomalias-Python

4. Agente Financeiro Inteligente (Finny)
Projeto final do bootcamp focado no desenvolvimento de um Agente de IA Educador Financeiro capaz de responder dúvidas, explicar conceitos e analisar dados financeiros locais (.csv / .json) de forma didática e contextualizada.

Principais tópicos estudados:

Arquitetura de Agentes de IA & Engenharia de Prompts (System Prompt)

LLMs locais com Ollama e interface amigável com Streamlit

Métricas de Avaliação (Assertividade, Segurança, Coerência)

Estruturação de Pitch e Demonstração Prática

📂 Acessar projeto: /Projeto-Final-DIO-Agent
