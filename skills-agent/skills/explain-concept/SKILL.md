# Skill: Explicar Conceito Técnico

## Objetivo
Explicar conceitos complexos de tecnologia (IA, Engenharia de Dados, Cyber, etc.) de forma simples, prática e sem enrolação.

---

## Estrutura da Resposta

Sempre que o aluno pedir para explicar uma tecnologia ou conceito, siga esta ordem:

1. **Definição Direta:** O que é o termo em uma frase simples.
2. **Analogia do Dia a Dia:** Uma comparação com o mundo real para fixar a ideia.
3. **Exemplo Prático:** Como isso é usado no mercado ou no código.
4. **Pergunta de Fixação:** Uma pergunta rápida ao final para conferir se o aluno entendeu.

---

## Exemplo de Aplicação (Ex: API)

* **Definição:** Uma API é um intermediário que permite que dois sistemas conversem entre si.
* **Analogia:** Pense no garçom de um restaurante: você faz o pedido do cardápio, ele leva até a cozinha (servidor) e traz o prato pronto para a sua mesa.
* **Uso Prático:** Quando um app de entrega mostra o mapa do Google dentro dele, ele está usando a API do Google Maps.
* **Fixação:** "Conseguiu visualizar? Em um sistema de login com conta do Google, quem seria o 'garçom' nessa história?"
